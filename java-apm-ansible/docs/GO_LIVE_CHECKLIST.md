# Go-live checklist

- [ ] Replace every sample hostname/IP and path in inventory/hosts.ini and vars/services.yml.
- [ ] Confirm inventory hostname exactly matches a key under java_apm.servers.
- [ ] Confirm every server hosts only one application type; list all JVM services and exact setenv.sh paths.
- [ ] Confirm all setenv.sh files are sourced by the real service launcher.
- [ ] Confirm start_app.sh spelling (singular) and stop_apps.sh/status_apps.sh spelling (plural).
- [ ] Confirm Walden-specific script filenames and paths; scripts manage all services on that host.
- [ ] Confirm script executable bits, shell interpreter, working directory, and service account privileges.
- [ ] Confirm status script returns nonzero when ANY required service is down; otherwise add output parsing.
- [ ] Confirm each service's New Relic app name; template currently replaces spaces with underscores (see README).
- [ ] Confirm New Relic labels syntax and approved team/service tag values.
- [ ] Confirm no unmanaged -javaagent option in existing setenv.sh; migrate first.
- [ ] Confirm no duplicate license_key in existing newrelic.yml and that its common section exists.
- [ ] Confirm Java compatibility with latest agent; validate Java version for every service, not just default java.
- [ ] Confirm target hosts can reach download.newrelic.com or use an approved internal artifact URL.
- [ ] Confirm AWX custom credential injects nr_license_key; use PROD/NPROD credential per job.
- [ ] Confirm backup/rollback plan and maintenance window for restarts.
- [ ] Test NPROD fresh install, old version upgrade, latest agent with missing setenv block, and unchanged rerun.
- [ ] Verify each JVM actually contains -javaagent and generates APM telemetry; status script alone is not enough.
- [ ] Confirm YAML permissions/ownership and script compatibility in staging.
